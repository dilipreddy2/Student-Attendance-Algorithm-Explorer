
# Student Attendance Algorithm Explorer

## About the Project
Student Attendance Algorithm Explorer is a web application that helps manage student records, track attendance, and understand searching and sorting algorithms.

## Features
- Add and view student records
- Record student attendance
- Calculate attendance percentages
- Linear Search
- Binary Search
- Bubble Sort
- Merge Sort
- Step-by-step algorithm explanations
- Time and space complexity

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- GitHub

## Algorithms

| Algorithm | Purpose | Time Complexity |
|---|---|---|
| Linear Search | Find a student | O(n) |
| Binary Search | Find a student | O(log n) |
| Bubble Sort | Sort attendance | O(n²) |
| Merge Sort | Sort attendance | O(n log n) |

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000 in your browser.
